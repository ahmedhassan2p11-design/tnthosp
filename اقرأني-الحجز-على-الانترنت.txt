الحجز الإلكتروني للمرضى من الإنترنت (GitHub Pages + نفق)
==========================================================

الفكرة
  المريض يفتح رابط GitHub Pages ← الصفحة تتصل بالخادم في المستشفى عبر نفق مشفّر ← الحجز يتسجل ويظهر
  عندك فورًا في البرنامج وأجهزة الاستقبال (مع صوت تنبيه).
  GitHub مجرد مكان لاستضافة شكل الصفحة (ملفات ثابتة). لا يحفظ أي بيانات مرضى. البيانات كلها تُحفظ عندك فقط.

المطلوب (مرة واحدة)
 1) في برنامج الخادم: إعدادات ← «التحكم في الحجز الإلكتروني» ← شغّل الحجز واختر العيادات.
 2) ارفع محتويات مجلد online-booking (كل الملفات والمجلدات داخله) إلى مستودع GitHub جديد:
      Add file ← Upload files ← اسحب المحتويات ← Commit
    ثم Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save.
    بعد دقيقة يظهر الرابط: https://اسمك.github.io/اسم-المستودع/
 3) شغّل النفق (على جهاز الخادم): ضع cloudflared.exe بجوار Start-Public-Tunnel.bat ثم شغّله.
    سيظهر عنوان مثل https://xxxx.trycloudflare.com
 4) افتح ملف config.js في المستودع على GitHub (Edit) واكتب العنوان:
      window.BOOK_API='https://xxxx.trycloudflare.com';
 5) افتح رابط GitHub Pages من موبايل وجرّب حجزًا.

عنوان ثابت (مستحسن للتشغيل الفعلي)
  عنوان trycloudflare المؤقت يتغير كل مرة يعاد فيها تشغيل النفق، فتحتاج تعدّل config.js كل مرة.
  للعنوان الثابت: حساب Cloudflare مجاني + نطاق (دومين) خاص بك ← Zero Trust ← Tunnels ← Create tunnel
  ← Public hostname: book.نطاقك ← Service: http://127.0.0.1:8790 . ثم ضع العنوان الثابت في config.js مرة واحدة.

الأمان والخصوصية (مهم)
  - المنفذ 8790 يخدم فقط: /pub/info /pub/saldays /pub/book /pub/lookup. أي مسار آخر (الحجوزات، المستخدمين، النسخ...) = 404.
    ويسمع على هذا الجهاز فقط، فلا يُفتح على شبكة المستشفى.
  - لا يوجد فتح للمنافذ في الراوتر؛ النفق يخرج من جهازك للخارج.
  - الصفحة لا تعرض بيانات مريض آخر، وفيها حد للمحاولات من كل جهاز.
  - بيانات المريض (الرقم القومي والموبايل) تمر عبر الإنترنت (مشفّرة HTTPS) عبر Cloudflare. تأكد أن هذا مسموح
    حسب تعليمات الجهة قبل التشغيل الفعلي.
  - لإيقاف الحجز من الإنترنت فورًا: أوقفه من «التحكم في الحجز الإلكتروني» أو أغلق نافذة النفق.
  - الخادم والنفق لازم يكونوا شغالين وقت الحجز؛ لو الخادم مقفول الصفحة بتقول «تعذر الاتصال».
